# figures_tables/

Manuscript-ready figures and tables. The three root files are the
submission masters; `figures_main/`, `figures_supp/`, and `tables/` hold the
individual panel/table files each master is assembled from.

| File | Contents |
|---|---|
| `Figures.pdf` / `Figures.pptx` | Main-text Figures 1–5 |
| `Supp_Figures.pdf` / `Supp_Figures.pptx` | Supplemental Figures 1–4 |
| `Supp_Tables.xlsx` | Supplementary Tables 1–14, one sheet each |

Panel (a) of every main figure, and panel (f) of Figure 1, are schematic
workflow diagrams assembled directly in the slide deck — they have no
generating script.

## `figures_main/`, `figures_supp/`

One `.png` + `.pdf` pair per generated panel, named `figure<N><letter>_<description>`
or `supp_figure<N><letter>_<description>` — e.g. `figure5b_model_benchmark`,
`supp_figure4a_window_confound_diagnostic`. `<N>` is the figure number,
`<letter>` the panel letter as captioned in `Figures.pdf`/`Supp_Figures.pdf`.
Each case study's own README documents which notebook cell writes which
file.

## `tables/`

One CSV per supplementary table, named `table<N>_case<M>_<description>.csv`
— e.g. `table12_case4_classification_model_benchmark.csv`. `<N>` matches the
sheet number in `Supp_Tables.xlsx` (`Supp_Table_<N>`); `<M>` is the case
study it comes from — table and case-study numbers run in the same order
(1–2 → case 1, 3–4 → case 2, 5–10 → case 3, 11–14 → case 4).

Two tables have no CSV here because they aren't pipeline-generated outputs:
**Table 11** (curated paclitaxel gene list) mirrors
`results/4_paclitaxel/pax_gene_list.tsv`; its `Function` column is written
by hand. **Table 14** (AIMS subtypes) mirrors
`results/4_paclitaxel/uhn_breast_pam50_aims_subtype.csv` — a real case
study 4 output, just not copied into `tables/`.

## Regenerating

Each panel/table file is written by a specific notebook cell, by path
(`paths["figures"]`, `paths["figures_supp"]`, or `paths["tables"]` from that
case's `pipeline_utils.py`) — rerun that case study's notebooks in order to
regenerate it. The three root masters (`Figures.pdf` etc.) are assembled
from these files externally (slide software) and are not themselves
generated by any script in this repo — re-embed updated panels by hand
after a rerun.
