# 0_xevaset_extraction/

Extracts the four source PDX XevaSet objects (`rawdata/`) into flat CSV/image
tables (`procdata/`), and builds the Figure 1 overview panels. This is the
only step that reads the raw `.rds` XevaSet objects directly — every
downstream case study reads from `procdata/`, not `rawdata/`.

Requires R with the `Xeva` package, plus `dplyr`/`ggplot2`. The last script
is a Python notebook (`pandas`, `matplotlib`, `seaborn`; see
`../requirements.txt`).

## Run order

| Script | Reads | Writes |
|---|---|---|
| `1-pdxe_tables_extraction.R` | `rawdata/pdxe/Xeva_PDXE.rds` | `procdata/pdxe/csv/` (models, expDesign, modToBiobaseMap, experiment, drug) |
| `2-pdxe_image_manifest_extraction.R` | `rawdata/pdxe/Xeva_PDXE.rds` | `procdata/pdxe/images/` (`*.webp` + `manifest.csv`) — case study 2's rendered tumour-volume images |
| `3-mcgill_breast_extraction.R` | `rawdata/mcgill_breast/Xeva_McGill.rds` | `procdata/mcgill_breast/` |
| `4-uhn_breast_extraction.R` | `rawdata/uhn_breast/UHN_Cescon_Breast_DrugResponse_2025_v1.rds` | `procdata/uhn_breast/` |
| `5-uhn_lung_extraction.R` | `rawdata/uhn_lung/UHN_Tsao_Lung_DrugResponse_2022_v1.rds` | `procdata/uhn_lung/` |
| `6-build_dataset_summary.py` | all `procdata/<cohort>/` tables above | `procdata/summary/dataset_summary.xlsx` (Sheet1 counts, Sheet2 cancer-type breakdown), `drug_dataset_overlap.csv` |
| `7-figure1_panels.ipynb` | `dataset_summary.xlsx`, `drug_dataset_overlap.csv`, and the separate hand-curated `database_summary.xlsx` | `figures_tables/figures_main/figure1b-e_*.png/.pdf` |

Scripts 1–5 are independent of each other (run in any order, or in
parallel); 6 depends on all of them; 7 depends on 6.

## Notes

- **`2-pdxe_image_manifest_extraction.R`** does more than extraction: it
  draws a stratified sample of 1,300 PDXE treatment/control batches (all
  eligible CR/PR kept, SD/PD splitting the remainder; `seed = 1`) and
  recomputes their sensitivity metrics on a fixed 10–50 day window to match
  the rendered images — see the script's own header for why. Its output
  feeds case study 2 (`2_drugSensitivity/`), not case study 4.
- **`database_summary.xlsx`** (consumed by `7-figure1_panels.ipynb`, Figure
  1e) is a hand-curated comparison of XevaDB against four external PDX
  resources (PDX Finder, EurOPDX, PDMR, PDXNet) — it is not generated by any
  script here and has no corresponding "regenerate" step.
- Figure 1 panels (a) and (f) are schematic diagrams assembled directly in
  the figure deck, not generated by any script.
