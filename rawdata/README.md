# rawdata/

Raw, unmodified inputs to the XevaDB pipeline. Nothing here is generated by
any script in this repo — each item is either the original PDX XevaSet
object delivered by the source institution, or an external data product
used as-is by one or more case studies.

## Other raw inputs

- **`expert_rating/`** — `pdx_results_expert{1,2,3}.json`. Independent
  ratings from 3 experts, each classifying a PDXE treatment-control batch's
  tumour-growth curve into one of 5 ordinal response categories. Read by
  `2_drugSensitivity/1-expertRating_preprocessing.ipynb` to build case
  study 2's ground-truth labels.
- **`nestvnn_gene_list/gene2ind.txt`** — the 718-gene panel NeST-VNN was
  trained on (tab-separated index + gene symbol). Used by case study 3 to
  build its mutation/CNV input matrices.
- **`I-SPY2_clinical_trial/`** — supplementary data from the I-SPY2-990
  Data Resource (Wolf et al. 2022, *Cancer Cell* 40:609-629,
  [doi:10.1016/j.ccell.2022.05.005](https://doi.org/10.1016/j.ccell.2022.05.005)),
  used by `4_paclitaxel/4-ispy2_validation.ipynb` to validate case study
  4's findings against a real clinical cohort:
  - `mmc2.xlsx` — Table S1, biomarker definitions
  - `mmc3.xlsx` — Table S2, patient-level scores + clinical/response data
  - `mmc4.xlsx` — Table S3, published per-arm pCR-association statistics
  - `mmc5.pdf` — supplementary methods (reference only, not read by code)
